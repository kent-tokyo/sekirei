About

Sekirei is an experimental, 100% Pure Rust shogi engine. Its core search and evaluation logic contains zero unsafe code — concurrency (a speculative parallel search with instant-cancel via atomics) is handled entirely through Rust's type system and safe primitives, not manual memory tricks. The project's current focus is search correctness and reproducibility, not chasing a playing-strength number.

This page exists because a real prospective integrator asked concrete questions about adopting Sekirei for a commercial mobile analysis app (see Docs & Links below) — the most useful answer is a small, honest, inspectable artifact, not a sales pitch.

Current limitations

  • No production-recommended NNUE weight file exists yet. Without one, Sekirei falls back to a genuine material-count evaluation — correct shogi play, but not the strength-relevant evaluation NNUE-class engines are built around.
  • No official iOS/Android FFI layer, C ABI, or JNI/Swift binding exists. The only currently supported integration surface is the USI protocol binary.
  • Floodgate rating is volatile — this project is under active testing, not a finished, benchmarked product.
  • This page cannot verify anything about a file you load — see the provenance badges in the viewer below.

Load an analysis record

Load a JSON, JSON-array, or JSONL file shaped like an analysis_record_v1 record (one position's engine analysis: SFEN position, per-candidate score/PV/bestmove, status). This viewer degrades gracefully on a partial or unexpected shape — it will show whatever fields are present rather than failing outright.
