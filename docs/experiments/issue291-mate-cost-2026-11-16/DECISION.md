# #291の現時点の判断：原因の一部を確認し、採用候補なしで停止

2026-11-16。固定ソース`14586edaf3a5e9e03739c2fa39c9e3f48e2cd56c`、公開11手詰6問、1T、評価重みなし。登録した[D01](D01.md)、[C01比較](AB01.md)、[O01比較](O01.md)を完了した。

用途別の計数では、Sekireiの完全着手632,305回のうち549,177回（86.85%）が子局面のハッシュ取得に使われた。C01はハッシュを盤面変更なしで計算し、着手数を大幅に減らした。6問の初手と`Solver::mid`訪問数は同一、全応手証明木も再生成・検証できた。しかし計数なし版の時間中央値合計は81.520→77.359msで5.10%の短縮にとどまり、事前の10%進行条件に不通過（`NO_PASS`）。完全着手の数だけでは実行時間の支配要因を表せない。

O01は固定ソースから独立に、攻方でpnが同値の有限候補だけ守方玉へ近い手を優先した。技術的な準備停止を経て有効なR3で84起動を完了。完全着手は632,305→612,352回（3.16%減）、時間中央値合計は79.726→82.027ms（2.89%増）で`NO_PASS`。6問の証明木は再検証済み。速度や節点数は局面ごとに異なるため、一局面の改善を全体改善に読み替えない。

次の候補として残る初期pn/dn推定は、選択・集約と子への閾値計算を一緒に変える必要がある。既存の費用内訳とO01の結果から、どの推定式が時間を改善するかを絞れない。固定式を根拠なく追加すると、安全性の負担だけが増える。この計画ではI01を登録・実行しない。持駒優劣の再利用や二重計上抑制など、別の機構の寄与も未測定である。

停止理由は`NO_MEANINGFUL_FEASIBLE_ACTION_WITHIN_REGISTERED_PLAN`。新しい計測が時間を支配する処理を示し、単独変更の仮説と独立入力を先に固定できる場合に限り、別の計画として再検討する。既知6問の反復増量やC01/O01の再試行はしない。通常探索の棋力、KHやYOとの同一条件の速度倍率、最短詰み手数は判定していない。

C01のソース差分は`c01.patch`に保存し、共有作業ツリーからのみ戻した。O01は隔離コピーで実行した。両候補とも既定へ統合しない。#291の費用調査はここまで記録したが、計画のクローズ条件である独立確認済みの安全で有効な修正には達していないため、issueはOPENのまま扱う。

## 続行後の判定：H01を統合候補とする

ユーザーの続行指示を受け、前試行の条件を変更せず、別の[D02 CPUサンプル](D02.md)で費用を調べた。固定11/14題の1,526スタックのうち、表検索と標準ハッシュ計算が最上位の733（48.0%）。この根拠から[H01](H01.md)で詰みソルバーの局所3表だけに整数キー用ハッシュを適用した。通常探索のTT、キー、値、探索規則は変えていない。

既知6題の事前条件を通過し、[独立9題の条件](H01-CONFIRM.md)も`PASS`。独立確認では8題の詰み回答を全応手証明し、1題の回答なしは両版で同じ訪問上限停止だった。時間中央値合計は2,247.168→1,608.954ms（28.40%短縮）、9題すべて改善、RSS退行なし。候補を共有`mate.rs`へ反映した。書式、詰み探索テスト、workspaceテスト、clippyを確認済み。初回workspaceテストは実行環境のローカルソケット禁止によりCSAの30件が失敗し、許可環境で全件再実行して通過した。カバレッジは実行していない。

この修正で確認したのは、登録した局面と条件での詰みソルバー費用と証明の維持。対局棋力、通常探索、KH/YOとの同一条件倍率は未確認。統合・issue解決はこの範囲で判断する。先のC01/O01の`NO_PASS`判定は変更しない。

PR #292の初回ホストCIは総合テストを含む16チェックが成功し、カバレッジのみ97.993%で既存98%ゲートを下回った。[H01記録](H01.md)のとおり、未実行だったバイト列`Hasher`経路の動作テストを追加した。初回CIの失敗を消さず、再実行を別コミットで確認する。
