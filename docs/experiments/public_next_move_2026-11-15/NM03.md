# NM03 著者解説付き実戦問題（探索前登録）

[実行結果](RESULTS-NM03.md)

別出典の[Haruto_shogi氏の原記事](https://note.com/haruto_shogi/n/n22eb048d7b97)から1題だけ固定する。問題図PNGのSHA-256は `3b0f93b7d9422c7a826781b2dda1eca68c623a1adb3394d941e0cb26c5a4bc59`。記事の想定解は▲5二銀、別の勝ち筋は▲6一飛、▲8三銀と▲8三飛には具体的な受けが示されている。これらは筆者の解説であり、全分岐の証明ではない。画像・解説本文をGitへ複製しない。

図面を独立に2回転記し、双方の駒・持駒を照合する。盤面81マス、双方の玉、駒種別の標準枚数、▲5二銀/▲6一飛/▲8三銀/▲8三飛と主要な記事応手の合法性を同一coreで検査する。転記者間に不一致、駒不足、主要手の不合法があれば入力未確定で停止する。色・手番・盤面を後から探索結果に合わせて修正しない。図面が確定したらSFENと元画像SHAを私有入力へ固定する。

入力が確定した場合のみ、現行r6（公開SHA、FV_SCALE24、absolute）の1T/冷プロセスで10万節点と100万節点の通常探索を各1回（外側合計10秒、RSS目安512MiB、出力1MiB）。返却手とPV合法性、完了深さ、著者の勝ち筋への一致を記録。不一致なら探索手と著者の想定解・別勝ち筋を同じ100万節点以下で強制root比較し、記事の反例手順を合法再生する。中断・深さ差・別解は未判定とし、問題の採点率・棋力率にしない。これ1題だけで探索定数を選ばず、実際に救済可能な失着なら同機構の別対局確認を次の候補条件とする。NM01/NM02の未使用確認15題は修正候補が固定されるまで使わない。
