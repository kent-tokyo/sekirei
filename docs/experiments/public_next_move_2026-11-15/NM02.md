# NM02 高難度の非詰み実戦問題（取得前登録）

[結果と停止理由](RESULTS-NM02.md)

NM01は一般カテゴリの開発12題で100万節点の明確な見落としが見つからなかった。新しい問いは、難度の高い公開実戦問題で短予算の見落としが同じ機構へ集まるか。NM01の不一致を増量して再判定する試行ではない。

Lishogi公開カテゴリ `endgame,advantage,middlegame,equality,crushing` の順に巡回し、最大60 GETまたは60秒で停止。取得時の本文SHA、URL、問題ID、元対局ID、rating、themesを保存する。NM01の24対局/問題ID、`mate`/`tsume`系テーマ、rating 2200未満、ゲームの重複を除き、先着最大24題を固定する。24未満でも選別基準や予算を変更しない。元棋譜を初手から合法再生し、問題局面と参考手を検証。収集した問題は前半を開発用、後半を未使用確認用として元対局単位で分ける。

開発用をr6/尺度24/1T/冷プロセスの10万・100万節点で順に計測し、全体外側60秒、各プロセス4秒、出力8MiB以内。参考手が違う題だけ最大4件で各候補を100万節点以下の強制rootで比較し、完了深さと中断も確認する。同種の低予算失着が元対局をまたいで2件以上あり、良い代替を強制探索で確認できた場合のみ、root順序など一つのopt-in候補を現行ソースの隔離checkoutに作る。候補設定・評価規則・同時間上限を凍結した後で、NM01/NM02の未使用確認側を一度ずつ計測する。未使用確認で改善と悪化を比べ、正式採用は独立対局H1の別契約へ進める。条件が満たされなければ候補を作らず停止する。
