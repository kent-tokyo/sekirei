# P01：H01適用後に残るCPU費用

2026-11-17。現行9f3539fをシンボル付きreleaseで隔離ビルドし、既知11/14題を100回、
同一processで逐次solve_mateする間、sampleを2秒・1ms間隔で1回実行する。
各呼出しの初手3b2a・46,297訪問と局面復元を検査する。
これは関数別費用の概算であり、速度比較や採用判定には使わない。

仮説：H01の整数ハッシュ化後も、集約ループの繰り返し処理などに短縮可能な時間が残る。
ソースから確認できる別候補は、各mid内で親のpathが不変なのに子ごとの反復判定を
各集約周回で再計算していること、最良子のcp/cdを直後に再取得していること。
プロファイルで該当箇所を判別できなければ推測で実装を選ばない。
候補を試す場合は単独変更を1件だけ、規則と上限を別途登録する。

条件：評価重みなし、1T、深さ25、各呼出し999,999訪問・内部8秒、process外側30秒。
sample外側8秒、RSS2GiB、出力32MiB。ビルド単一ジョブ・5分、追加領域2GiB以内。
固定ソース・driver・binary・入力・sampleツールのhashを実行前に保存する。
異常時はprocessを終了・回収し、未測定として停止する。
