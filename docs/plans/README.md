# 強化計画の棚卸し

更新: 2026-11-17。

**リセット以前の進行中・保留中の計画はすべて終了。現在、新たな強化実験は選定していない。**
この棚卸しは過去の判定と未確認事項を探す入口であり、後続実験の指示ではない。

## リセットの対象

ユーザーの「中途半端な計画はいったんリセット」「なかなか強くならないので、
全ての進行中計画を見直す」という指示による。
対象はこのディレクトリだけでなく、ローカルの`ROADMAP.md`・`tasks/`、
設計文書、実験記録に残る継続・再開予定を含む。

旧資料の「次の作業」「条件が揃えば再開」は現行の指示として扱わない。
原本の計画・試行条件・判定は保持し、未完了を完了や成功へ読み替えない。
新しい方針が決まるまで、追加学習・対局・候補選択・統合を開始しない。
